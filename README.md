# 📸 PIXEL POP ★ Y2K Scrapbook Photobooth

> **Instant Y2K Cyber Scrapbook Photobooth Web Application**  
> Snap 4 retro poses via webcam or upload photos, customize with vintage stickers & flash filters, and export high-res printable 300 DPI strips. 100% client-side privacy.

---

## ✨ Features

- 📷 **Multi-Shot Studio**:
  - Live webcam feed with 3-second audio-visual countdown and flash effect
  - 4-pose sequential shooting
  - Photo upload fallback (upload 4 custom pictures)
- 🎨 **Y2K Retro Frames & Layouts**:
  - Classic 2x2 Grid or Vertical Photostrip
  - Y2K Color Themes: Baby Blue, Cyber Pink, Lime Glow, Holographic Silver, and Dark Mode
  - Customizable title text and retro timestamp
- ⭐ **Interactive Scrapbook Canvas**:
  - Drag, rotate, resize, and delete retro stickers & doodles
  - Vintage Camera Flash Filters: Vintage Warm, Cool Cyber, Retro B&W, Sepia, Pop High-Contrast
- 💾 **Instant High-Res Export**:
  - Download crisp PNG ready for printing
  - 1-Click Copy Image to Clipboard
  - Native Web Share API integration (mobile-ready)

## 🛠️ Tech Stack

- **Core**: HTML5, Vanilla JavaScript (ES Modules)
- **Engine**: HTML5 Canvas 2D API (High-DPI rendering)
- **Styling**: Tailwind CSS, Epilogue & Plus Jakarta Sans typography
- **Bundler**: [Vite](https://vitejs.dev/)

## 💻 Local Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/<YOUR_GITHUB_USERNAME>/<REPO_NAME>.git
   cd <REPO_NAME>
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local development server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser.

4. **Build for production**:
   ```bash
   npm run build
   ```
   The production-ready output will be in the `dist/` directory.
