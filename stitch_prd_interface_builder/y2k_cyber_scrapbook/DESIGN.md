## Brand & Style

This design system channels early-2000s cyber-cute nostalgia through a tactile, retro-digital scrapbook aesthetic. It pays homage to classic web photobooths, early desktop OS chrome, decorative stickers, and bubbly toy electronics while maintaining contemporary accessibility and precise usability.

### Brand Personality & Core Mood
- **Playful & Nostalgic:** Reminiscent of digital cameras, personal blogs, sticker sheets, and metallic tech accessories from the turn of the millennium.
- **Expressive & Tactile:** Features glossy pill buttons, dimensional bevels, holographic shimmer, and sticker badges that look ready to peel.
- **Approachable & Streamlined:** Despite the rich visual flourishes, functional task flows (capturing photos, arranging frames, adding stickers, and downloading) remain clutter-free and intuitive.

### Design Style Mix
The visual direction balances **Y2K Retro Digital / Skeuomorphic Bubble Chrome** with **Clean Modern Utility**:
- **Glossy UI Chrome:** Gradient fills mimicking translucent plastic casings, metallic sheen borders, and candy-colored glass pills.
- **Scrapbook Tactility:** Drop-shadow stickers, tilted instant photo frames, subtle dot matrices, and checkerboard canvas backgrounds.
- **Balanced Legibility:** Display titles use geometric, bubbly forms, while operational controls, tooltips, and file states leverage crisp, humanist geometric sans-serif type.

## Colors

The color palette captures an iridescent Y2K aesthetic using pastel cyber shades tempered by deep ink tones for contrast and accessibility.

### Palette Hierarchy & Intent
- **Primary (`#FF69B4` / Hot Pink):** Used for primary calls to action, countdown indicators, and prominent active tool states. Supported by its softer tint `bubblegum-soft` (`#FFB7D5`) for pill fills and hover glows.
- **Secondary (`#70D6FF` / Cyber Sky):** Drives camera actions, selection rings, framing accents, and secondary toggles. Paired with `baby-blue` (`#B4E4FF`) for inner container bevels.
- **Tertiary (`#BDB2FF` / Lilac Dream):** Deployed across tool ribbons, active sticker borders, and badge tags to create a candy-pastel spectrum.
- **Neutral (`#4D4665` / Retro Slate Ink):** Provides deep purple-slate body text and secondary metadata, avoiding stark jet-black to keep the scrapbook warmth intact.
- **Canvas & Background (`#F8F7FF`):** A soft, pearlescent off-white backdrop that supports subtle checkerboard and dot-grid textures without straining the eyes.

### Metallic & Holographic Accent System
- **Chrome Gradients:** Used on floating modal headers, retro browser bars, and button bevels: linear gradient of `chrome-shine` (`#FFFFFF`) to `chrome-silver` (`#E2E8F0`) with a `chrome-edge` (`#94A3B8`) 1px hairline stroke.
- **Holographic Rainbow Shimmer:** Linear gradient (`135deg, #FFB7D5 0%, #BDB2FF 35%, #A0E7E5 70%, #FFD166 100%`) reserved for sticky badges, VIP export triggers, and celebratory flash transitions.

## Typography

The type system blends expressive turn-of-the-millennium personality with clear modern digital legibility.

### Font Hierarchy
1. **Headlines (`Epilogue`):** Expressive, slightly wide, and punchy. Bold weights evoke early digital pop art, stickers, and arcade titles without becoming illegible.
2. **Body & Instructions (`Plus Jakarta Sans`):** Warm, geometric, and welcoming. Provides clean reading comfort for upload instructions, webcam permissions, and error handling dialogues.
3. **Labels, Counters & Monospaced Accents (`Space Grotesk`):** Provides a retro-technological cadence for tool labels, countdown clocks (`03`, `02`, `01`), coordinate markers, and frame sizes.

### Usage Standards
- Display titles may use subtle 1px stroke outlines or drop-shadows (`2px 2px 0px #2B213A`) to mimic 2000s desktop window titles and sticker cutouts.
- All functional form controls and status notifications remain set in un-stroked `Plus Jakarta Sans` or `Space Grotesk` for immediate accessibility.

## Layout & Spacing

The layout model is built around a hybrid workspace: a centered, photostrip-focused stage flanked by tactile tool decks.

### Grid & Layout Structure
- **Desktop Studio (`≥ 1024px`):** Fixed left tool rail (72px collapsed or 240px expanded), centered flexible canvas viewport with responsive padding (`space-xl`), and right-hand floating properties inspector (280px). Bottom photo tray maintains a 100px fixed height with horizontal snap-scroll.
- **Tablet / Laptop (`768px - 1023px`):** Top session bar, centered photostrip canvas with auto-scaling boundaries, and bottom docked dual-row tool selector.
- **Mobile (`< 768px`):** Single-column stacked viewport. The canvas occupies top priority with safe margins (`margin-mobile`), while tools live inside an expandable bottom sheet that shifts between compact icon rows (56px) and active property sliders (max 45% screen height).

### Spacing Cadence
- Element spacing strictly follows a 4px/8px incremental base (`space-xs` = 4px, `space-sm` = 8px, `space-md` = 16px, `space-lg` = 24px, `space-xl` = 40px).
- Gutters within sticker grid trays and filter thumbnail scrollers use `gutter-sm` (12px) to pack maximum visual choices without crowding tap targets.

## Elevation & Depth

Visual hierarchy uses tactile Y2K physical metaphors: drop shadows, metallic rim highlights, and layered scrapbook tiers rather than standard web blur shadows.

### Depth Layers
1. **Ground / Canvas Backdrop:** Patterned base with subtle retro dot-grid (`#E2E8F0` 2px dots on 20px pitch) or soft pink-blue micro-checkerboard.
2. **Scrapbook Stage (Photostrip & Frames):** Elevated with hard-edged, warm drop shadows: `box-shadow: 4px 4px 0px 0px #2B213A`. Photostrip borders use glossy white cardstock style with an inner rim highlight: `inset 0 1px 0 rgba(255, 255, 255, 0.9)`.
3. **Interactive Floating Windows & Dialogs:** Retro desktop browser chrome windows feature a dual-layer bevel: `box-shadow: 6px 6px 0px #2B213A, inset 1px 1px 0px #FFFFFF`.
4. **Stickers & Peelable Elements:** Dynamic hover states induce a slight perspective tilt (`transform: rotate(-3deg) scale(1.05)`) paired with a deeper offset shadow (`4px 6px 0px rgba(43, 33, 58, 0.25)`).
5. **Bubble Buttons & Pills:** Dual-tone glossy skeuomorphism via linear vertical gradients (`linear-gradient(180deg, rgba(255,255,255,0.6) 0%, rgba(255,255,255,0) 50%, rgba(0,0,0,0.08) 100%)`) layered with a crisp bottom rim (`border-bottom: 3px solid #2B213A`).

## Shapes

The shape vocabulary revolves around rounded rectangles, soft pill silhouettes, and organic starburst cutouts.

### Geometric Rules
- **Base Rounding (Level 2):** Standard containers, photostrip individual picture slots, and panel cards feature a balanced `0.5rem` (8px) radius.
- **Pill Cutouts (`rounded-full`):** All action buttons, sticker filters, countdown chips, and input pills adopt continuous curvature (9999px) to capture the early 2000s glossy toy and candy aesthetic.
- **Window Frames & Browser Chrome:** Headers, tool rails, and dialog frames use `rounded-lg` (16px) outer corners with crisp 2px solid structural borders (`#2B213A`).
- **Accent Motifs:** Decorative elements, sticker anchors, and framing handles incorporate 4-point sparkle stars, daisy flower badges, and heart-shaped bounding controls.

## Components

### Buttons
- **Glossy Bubble Button (Primary):** Pill-shaped with hot pink fill (`#FF69B4`), 2px solid dark border (`#2B213A`), top-half white glossy gradient shine, and a 3px hard bottom shadow. On press: translates down 2px with shadow collapsing to 1px.
- **Chrome Cyber Button (Secondary):** Brushed metallic silver fill gradient, baby blue inner stroke, 2px border, Space Grotesk semi-bold uppercase text.
- **Ghost Sticker Button:** Flat transparent surface with a dashed 1.5px border (`#BDB2FF`), transitioning to full pastel lilac fill on hover.

### Photostrip Frame Slots
- Crisp polaroid/strip card border (`#FFFFFF`) with 2px stroke outline (`#2B213A`).
- Inner photo cutout with rounded corners (4px), maintaining fixed aspect ratios (4:3 or 1:1 depending on layout preset).
- Empty/Upload state features an animated holographic dashed outline with a retro pixel '+' icon in the center.

### Sticker Tray & Badges
- Compact card grid displaying stickers over light checkerboard tiles.
- Hovering a sticker produces a 6-degree rotational wiggle and cursor change to a hand-grab icon.
- Active stickers on canvas display a dashed selection marquee with 4 circular corner scale handles and 1 top rotating stem handle styled like a cherry or sparkle star.

### Filter & Layout Selector Chips
- Pill-shaped horizontal selector chips.
- Inactive state: Translucent white glass background (`rgba(255, 255, 255, 0.7)`), 1px slate border.
- Active state: Cyber Sky (`#70D6FF`) fill, bold text, accompanied by a small floating sparkle icon.

### Form Inputs & Text Editing Overlays
- Scrapbook text entry uses pill or rounded-rectangle fields with soft inner shadows (`inset 1px 2px 3px rgba(0,0,0,0.1)`), mint-pop or baby-blue focus outlines, and Space Grotesk helper labels.
- On-canvas text elements provide direct inline editing with font-family selectors styled like early digital label-makers.

### Retro Browser Window Dialog (Capture & Export Modals)
- Window title bar featuring simulated early web browser controls: 3 small colorful candy dots (pink, yellow, green) on the left, a centered centered title in Epilogue, and a square 'X' close box with a hard drop-shadow.
- Body area contains framed webcam feed, countdown numbers rendered in large bold Space Grotesk, and status tooltips.
